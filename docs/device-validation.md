# 真机验收（待执行）

环境：Mac + Xcode 16 以上；USB-C iPhone，iOS 18 以上；exFAT SSD 为主，另测 APFS。记录 iPhone 型号、iOS/Xcode 版本、硬盘和连接线型号、供电方式、耗时及峰值内存。以下项目不能由 Linux 模拟测试替代。

## 连接与授权

- 首次目录授权、关闭后重开、重新插盘、手机重启后的 Bookmark 恢复；失效时可重新选择。
- 父目录创建档案、直接选择原档案、同名非空目录拒绝覆盖、只读盘和空间不足。
- 完整、有限和拒绝照片权限；授权范围变化时无“全部备份成功”误报。

## 资源与网络

- HEIC、JPEG、PNG、截图、连拍、隐藏照片、普通视频、大视频、RAW+JPEG、Live Photo。
- 调色、裁剪、慢动作和编辑过的 Live Photo：确认原始资源选择；界面不宣称保留编辑效果。
- 默认云端原片列为待下载；开启下载后可完成；断网、下载取消及 Live Photo 仅一半在本地时无假成功。
- 导出内容使用独立工具计算 SHA-256，与收据核对；人工检查媒体可解码、Live Photo 两个资源俱全。

## 中断与一致性

- 写入、读回、正式文件移动、记录提交阶段分别拔盘、强退、锁屏或切到后台。
- 重连和继续后，没有损坏文件被当成成功；已完成资源不重传；未完成大视频从头开始。
- 人为删除硬盘文件；用相同长度内容修改文件；完整校验可发现并安排重传，原异常文件保留。
- 截断单资产 JSON：该资产提示需检查，其余资产可继续；截断档案头/事务：停止写入且保留证据。
- 更换挂载路径后仍识别 archiveID；两块盘、同一盘两个档案的状态互不混用。

## 增量、规模与恢复

- 一万张以上混合资产分多轮完成；统计成功、待下载、失败之和与授权范围一致。
- 重复运行不重新导出；新增照片只传新增；后来导入的旧日期照片可被识别。
- 调整图片效果不创建原片新版本；原始资源描述变化时保留旧版本并创建新代。
- Photos 删除照片后硬盘文件仍在。
- 连续处理大视频，内存不随视频大小及总原片数量增长；记录元数据扫描和传输阶段峰值。
- 卸载重装后从硬盘重建缓存，显式重新关联原照片库；无法核对时阻止误跳过。
- 换手机作为新照片库运行，默认允许重复，不自动宣称跨设备匹配。

## 通过条件

完整完成上述检查，记录发现的问题并修复后复测。模拟器构建通过、核心单测通过、元数据万张测试通过，均不能单独作为真实照片备份可靠性验收结论。

## 目录选择与硬盘照片浏览

- 首次用系统界面授权硬盘根目录后，在应用内只显示文件夹；根目录有 8,000 张以上照片时，列表不生成照片缩略图，等待期间显示进度。
- 输入中文文件夹名并“创建并选用”：创建后直接返回，备份目标为新目录；系统选择器“打开”后直接生效，不再二次确认。重名、非法名称、只读盘、创建中拔盘须报错，不自动改名或覆盖。
- 重新打开目录选择：恢复已授权位置，能够返回授权根目录；取消系统授权保持原位置。子目录加载时确认、取消和返回仍可用。
- 外置盘根目录标题优先显示系统提供的可读名称；系统仅提供 UUID 时显示“外置硬盘”。检查备份卡片和文件页均无 UUID 泄漏。
- 文件页标题单行显示，长目录路径截断；切换 3/4/5 列缩略图后重开保留设置。
- 点击照片后全屏预览，滑动只经过当前筛选和排序中的照片/视频，不混入文本等文件；检查缩放、视频播放、关闭和返回原滚动位置。

## 文件页删除

- 网格照片、视频、普通文件及文件夹行长按均有“删除”，取消确认后内容不变；开启 VoiceOver 时也可通过删除操作进入确认。
- 确认框显示准确名称，文件夹明确提示全部子项将永久删除。分别测试空文件夹、非空文件夹、照片和视频，删除后列表与预览顺序同步刷新，其他项目保留。
- 创建专用临时文件验证，只读盘、拔盘、提供方拒绝删除均显示错误并重新读取目录，失败不误报成功。
- 大文件夹删除期间显示进度，禁止重复操作和切换应用内标签；备份、扫描、校验、连接目录期间删除入口禁用。
- 不显示隐藏档案目录，不提供删除当前根目录的入口；符号链接删除不得影响其指向目录。

## 照片范围分层选择

- 首页只显示全部／按日期／手动三个入口及当前摘要，日期和手动控件不在首页混排。
- 按日期进入二级页：只有选中自定义日期才展开日期控件；返回不改变原筛选和起止日期，确认后才生效。
- 手动挑选在同一网格切换逐张／首尾模式，切换后清空已选集合，保留相册和滚动位置；取消保留原选择，确认提交真实已选数量。
- 首尾计算期间禁止切换模式；已有选择恢复期间也禁止切换，避免异步任务覆盖新选择。未选完首尾时确认应提示补选。
- 手动选择页的取消返回方式选择页，不误关闭整个设置流程；照片预览仍可正常返回网格。

- 首尾选中跨越多屏的区间后，滚动回到刚出现的格子，所有选中项都应显示连续编号，蒙层与真实选中状态一致。
- 扫描页部分预览明确写出展示数量与待备份总数；同原因警告合并计数，展开可找到受影响照片，待检查数量与摘要一致。

## HEIC 与长视频

- 手动逐张选择、首尾连续选择及全部／日期扫描都允许超过 120 秒的视频；验证一段超过 2 分钟的本地视频和一段较大的视频。选择器不设置视频时长／文件大小上限，仍正常提示空间不足或云端待下载。
- HEIC 原片不转 JPEG，保留原名与原始字节，独立计算 SHA-256 核对；扫描中的资源问题须区分未知辅助资源、原片未就绪和不可导出，不按扩展名判断不支持。
- Debug 可用 `--review-screen resources --diagnose-photo-resources` 只扫描照片资源元数据，在应用 Documents/DesignReview/photo-resource-diagnostics.json 生成被排除项目的诊断；不导出照片原图，不写入外置盘。

- 真机诊断确认 13 张 HEIC 含原始 .photo 以及 type=16、UTI=com.apple.photos.apple-adjustment-envelope 的 .aae 调整数据。只将此特定组合识别为附加调整信息，不阻止原片备份；其他未知类型、缺少原片或 Live Photo 配对视频仍需检查。修正后重新扫描同一照片库，核对这 13 项不再因 type 16 被排除。

2026-10-26 真机复查：同一 iPhone 照片库扫描 3,041 项，修正前 13 项因 type 16 被排除；修正后重新扫描，资源检查排除数为 0。此项验证元数据扫描与兼容性判断，不等同于这些原片已完成导出及读回校验。

## 启动与元数据缓存性能回归

- 已存硬盘书签的用户启动先显示首页，未连接或缓慢硬盘不阻塞文件／历史／设置导航。连接完成后首页计数自动扫描，不错误显示首次欢迎页。
- 照片逐张勾选、滑动选择、首尾多选时不自动请求完整原图；仅预览按需加载。关闭“允许下载云端原片”后仍不得因勾选绕过此选项而预取原图。
- 连续相同范围扫描结果一致，第二次减少资源查询；新增、删除、编辑照片或修改授权后重新扫描反映变化，不继续复用旧描述。
- 新增资源／更改原片后实际导出应重新核对描述；外置盘上删除已备份文件后再次备份仍会安排重传。

## 无磁盘缓存的滚动加载

- 快速划过多屏照片后停下，当前可见照片应继续加载；返回已看过的区域可命中原有内存缓存。
- 网格／列表、3／4／5 列切换后可见缩略图正常加载；文件内容或元数据变化后刷新可更新图片。
- 不新增应用磁盘缩略图缓存目录，原片只读，不修改外置盘文件。

## 温暖相册主题与统一日期框

- 欢迎、首页、备份中、成功／部分失败、文件、历史、设置及照片范围使用暖白、陶土、柔绿主题；待处理项保持警告色、数量和具体说明，不被成功文案覆盖。
- 首页准备状态不显示虚构待备份数量；主操作和备份目录在常用屏幕尺寸可见，较大字体时可滚动。
- 自定义日期的起止字段都使用 184pt 宽、至少 44pt 高的按钮，短日期、长日期和不同语言不会改变字段宽度；点击弹出系统日历，选日后关闭，开始不能晚于结束，结束不能早于开始。
- 日期草稿只在确认范围时提交；返回仍保留原选择。新主题没有改变备份引擎或照片加载策略。

- 首页按位置 → 照片范围 → 底部开始操作排列，顶部相册只显示状态。未选位置时开始按钮禁用；位置选好后留在首页继续选范围。备份中底部仍可查看进度。
- 验证 1 月 2 日显示时月份为“01”、日期为“02”，日期框及范围摘要格式一致，日期框宽度不随内容改变。
