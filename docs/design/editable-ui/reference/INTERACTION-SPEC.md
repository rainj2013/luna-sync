# Luna Sync · 交互与状态规范

## 核心原则

1. 工具用于本地将 iPhone 照片与视频增量备份到 USB-C 移动硬盘。界面不触发外部多模态模型、不上传照片、无账号依赖。
2. 增量同步记录持久化：已完整提交的资源不重复备份。App 重启、断线重新连接仍能恢复已提交状态；硬盘端独立 manifest 和手机端任务记录协同。
3. 向外接目录写入依赖系统文件选择器与安全作用域授权；**不可将模拟设备列表视作绕开系统文件授权的真实能力**。
4. 备份完成后必须有可靠成功判定；不能因为复制 API 返回或 UI 计数增加就把资源标记为成功。实际实现应提交临时文件、验证、原子/安全移动与更新 manifest。
5. 默认只追加，不删除硬盘历史备份。删除 iPhone 端照片不应删掉硬盘文件。
6. 文件浏览所选目录与备份目标目录相互独立。用户打开任意目录不会偷偷变更备份目标。
7. 长任务属于前台体验；进入后台/断电/拔盘要能再进入并恢复，不能承诺 iOS 不受限后台持续写入。

## 页面与主要迁移

| ID | 状态 | 行为 | 下一状态 |
|--|--|--|--|
| 01 | 首页-硬盘未连接 | 点备份位置 | 03 选择目录 |
| 02 | 首页-硬盘已连接 | 点开始增量备份 | 04 扫描 |
| 03 | 选择目录 | 点「打开系统文件选择器」 | 唤起 iOS 文件选择器，授权成功后回到 02 |
| 04 | 扫描中 | 扫描完成 | 05 备份确认（若无新增则展示“已是最新”状态） |
| 05 | 备份确认 | 点开始备份 | 06 备份中 |
| 06 | 备份中 | 点暂停 | 07 已暂停 |
| 06 | 备份中 | 全部提交成功 | 08 完成 |
| 06 | 备份中 | 部分文件失败 | 13 错误与重试 |
| 07 | 已暂停 | 点继续 | 06 继续未提交资源 |
| 08 | 完成 | 点查看文件 | 11 文件已连接 |
| 09 | 备份记录 | 点击记录 | 任务详情/结果，保持现有项目的详情能力 |
| 10 | 文件-硬盘未连接 | 点选择目录 | 调用系统文件选择器，成功后显示 11 |
| 11 | 文件-硬盘已连接 | 顶部文件夹按钮 | 重新选择浏览目录，**不修改备份位置** |
| 12 | 设置 | 完整性校验、重新检查 | 14 备份完整性 |
| 13 | 失败 | 重试失败项目 | 仅处理失败项目，返回 06 |
| 14 | 完整性 | 点击重新检查 | 重新检查硬盘中的备份文件 |

## 重要边界状态（实施时必须覆盖）

- 首次启动，照片授权未授予 / 仅允许部分照片访问。
- 磁盘未连接、目录授权丢失、连接后目录书签失效。
- 权限被撤销、磁盘空间不足、写入失败、文件已经存在但记录缺失。
- 本地原片不存在，iCloud 下载中或失败；此时不得标记该资源已备份。
- Live Photo 的静态图与配套视频有单独资源状态；全部成功才算完整。
- 扫描完成但没有新增：使用简洁的“已是最新”状态，不能显示 0 个文件的大成功庆典。
- 备份任务暂停/取消/中断/恢复和可能的部分失败。
- 换一块硬盘：按该硬盘的 manifest 单独计算增量；不能套用上一块硬盘的记录。
- App 被卸载后从硬盘索引恢复，确保已有文件不会被盲目重复写入。
- 大字体、较长设备名、辅助功能、低电量、低可用空间和横屏边界情况。

## 组件规格

- 画布：393×852 pt；状态栏预留约 59 pt、内容左右边距 24 pt、Tab Bar 顶部 y=765，按实际机型 Safe Area 调整。
- 页面底色 `#FCF8F2`；卡片 `#FFFFFF`；Hero `#F4ECE1`；文字 `#3F3530`；次要 `#857A73`；主操作 `#98543F`。
- 主要按钮 54pt 高 / 17pt 圆角；列表项约 77pt 高 / 19pt 圆角；Hero 27pt 圆角。
- 页面标题 22pt，强调文案 23–27pt，普通文字 13–15pt，辅助文字 11–12pt。**不要用画板中的固定字号阻断 Dynamic Type**。
- 状态颜色有语义才出现：成功低饱和绿 `#617969`，警告 `#B97838`，错误 `#BE6658`；避免分数仪表盘与红绿对抗。
- 禁止增加临时无用插画、重复说明、全屏装饰标题、每个图标外套显眼色块。
- 动效可用原生 SwiftUI 低振幅过渡，支持 Reduce Motion。

## 首页与文件页特别强调

**首页（01/02）**：品牌标识、Hero 主状态、备份位置、照片范围、唯一 CTA、底部导航。断盘时说明不超过两行，不能同时出现三处相同警告。

**文件页（10/11）**：继续保留「备份」「记录」「文件」三 Tab。文件页是单独浏览外接目录；在无磁盘时展示空状态而非产品介绍；有文件时内容网格主导视觉。
