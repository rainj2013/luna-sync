# 给 Codex 的执行任务：Luna Sync 视觉精修

你正在维护一个已有业务代码的 iPhone 照片备份 App，名称 **Luna Sync**。请按下列方式实施 UI 微调，**禁止重新开发功能**。

## 输入优先级

1. 当前项目中的真实交互与现有逻辑（最高优先级）
2. `INTERACTION-SPEC.md` 的状态和约束
3. `screens/*.svg` 中各页面的可编辑设计稿
4. `design-tokens.css`、`tokens-and-screens.json` 中的颜色与尺寸
5. `previews/*.png` 作为视觉验收参考

## 具体任务

1. 阅读项目现有 SwiftUI 页面/导航和资源层，先做差异报告，列出需要修改的文件，不要假定当前项目页面名称。
2. 建立或整合语义 Design Tokens，集中管理 Color、Spacing、Typography、Radius；优先重用已有组件，不重建并行 UI 框架。
3. P0：对齐 01 首页-未连接、02 首页-已连接、10 文件-未连接、11 文件-已连接；特别留意既有 App 的三栏 Tab 与独立文件浏览入口。
4. P1：对齐 04 扫描、05 确认、06 正在备份、07 暂停、08 完成、13 错误状态。
5. P2：对齐 09 记录、12 设置、14 完整性、03 选择目录。
6. 所有文字与 UI 通过 Dynamic Type / Localization 表达，不要硬编码演示数字、硬盘名、扫描进度。演示矢量缩略图必须替换为真实缩略图资源（并在加载时注意主线程性能）。
7. 运行能运行的构建、测试和静态检查，并在可用环境提供原生 SwiftUI 截图和逐屏差异对比。

## 非法改动（禁止）

- 不能新增任何服务器上传/外部 AI 处理。
- 不能为了对齐 UI 而改写备份数据模型、增量算法、硬盘目录结构、权限请求或已存在的正确逻辑。
- 不能将演示中的设备列表误做成一个能够自行枚举所有 USB 硬盘的承诺；依照 iOS 官方文件选择器能力实现。
- 不增加当前需求之外的功能、Tab、头像或底部工具栏。
- 不改成其他品牌配色；保留奶油白 + 低饱和褐红、月亮 Logo、拍立得插画语言。

## 完成标准

- [ ] 三 Tab 及既有页面不丢失功能。
- [ ] 首页未连接、已连接、扫描、备份、暂停、完成、失败均状态准确。
- [ ] 本地增量记录与外接硬盘校验逻辑无回归。
- [ ] 文件浏览目录与备份目标权限互不干扰。
- [ ] 所有可点击控件满足最低 44×44pt 点击区域。
- [ ] iPhone SE / 常见 6.1–6.3 英寸设备 / 较大字体布局不溢出；考虑 Safe Area。
- [ ] 对比输入 SVG 与运行截图，不要只换色。

**优先给出 plan + 修改清单，再落实代码；最后展示真实运行截图和验证结果。**
